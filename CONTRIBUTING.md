# Contributing to Offline-36

First off, thank you for considering contributing to **Offline-36**! Projects like this rely on community support to grow off-grid communication tech.

### 🌟 Quick Ways to Support
- **Star this repository** — it helps increase visibility for emergency and off-grid solutions!
- **Test on real devices** — test multi-device mesh routing and report edge cases via GitHub Issues.
- **Spread the word** — share the project with developers interested in mesh networking or offline-first apps.
